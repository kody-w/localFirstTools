guideRun it yourself, step by step · the Short · all episodes · data
Build a 3D mechanical keyboard configurator in ONE self-contained HTML file. No libraries, raw WebGL2 only.

Model
→ 75% gasket-mount board, 82 keys with an F-row, an aluminum rotary knob and an artisan Esc
→ sculpted Cherry-profile keycaps with dished tops, homing bumps and two-line legends that sit on the caps in perspective
→ full stack: switches with stems, stabilizers, gaskets, brass plate, plate foam, hot-swap PCB with diodes, case foam, two-tone CNC case with a brass weight
→ coiled USB-C cable with an aviator connector, color-matched to the keycaps

Interaction
→ drag to orbit with inertia, scroll to zoom
→ Explode: layers lift apart in a staggered cascade, each layer gets a clean label that never overlaps
→ switch selector: keys lift in a wave to reveal the new stems, then drop back
→ colorway and case swatches with a ripple recolor
→ RGB toggle with Wave / Breathe / Ripple effects, shine-through legends and underglow
→ typing test field: every typed character presses the matching key

UI
→ beige studio background, spec chips, segmented controls, toolbar, floating card with swatches, toast on share
→ 60fps, zero console errors, works offline
