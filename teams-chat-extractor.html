How to use

  1. Drag the purple button above to your Edge bookmarks bar.
  2. Open Teams web (teams.cloud.microsoft or teams.microsoft.com) and click into the chat you want to export.
  3. Make sure the chat pane has focus (click any message once).
  4. Click the Extract Teams Chat bookmark.
  5. Wait a few seconds — a status pill appears top-right while it scrolls and collects.
  6. When done, the transcript is copied to your clipboard AND downloaded as a .md file.
Tip: If the chat is huge (1000+ messages), let it run — it scrolls to the very top in chunks. The status pill shows the running message count.
Heads-up: Teams DOM changes occasionally. If you get "No chat scroller found", click directly on a message in the chat first, then run the bookmarklet again. The script tries several selectors plus a generic fallback.

    Troubleshooting
    
    
      
  • "No chat scroller found" — click a message in the chat to give it focus, then run again.
    • 
      
  • Clipboard didn't copy — Edge may block clipboard after long async work. The .md file still downloads.
    • 
      
  • Some messages missing — Teams virtualizes aggressively. The bookmarklet does two passes (scroll up, then back down). Run it twice to be sure; the second run will collect more.
    • 
      
  • Files / images / reactions — only text content is extracted. Images and file cards become their innerText alt/label.
    • 
      
  • Doesn't work in the Teams desktop app — bookmarklets only run in browsers. Use Teams in Edge (web).
