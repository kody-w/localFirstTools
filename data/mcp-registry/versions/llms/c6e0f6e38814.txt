# MCP Registry

Public MCP server discovery; a read-only, offline-buildable catalog.
Pages base: https://kody-w.github.io/localFirstTools
Raw fallback base: https://raw.githubusercontent.com/kody-w/localFirstTools/main
Data folder: data/mcp-registry/
Catalog: api/v1/servers.json (complete MCP server entries)
Index: registry.json (SHA-256 first 12 hex and immutable versions)
Chain: chain.jsonl (rapp/1); discovery head: orient.json
Status: api/v1/status.json; badge: api/v1/badge.json
Inputs: manifest.json and servers/*.json
Build offline: python3 -B data/mcp-registry/build.py
Agent: agents/mcp_registry.py; perform(tool=...) returns exact tool matches.
Tools are curated discovery subsets; consult upstream for the full inventory.
No installation or remote execution occurs during discovery.
